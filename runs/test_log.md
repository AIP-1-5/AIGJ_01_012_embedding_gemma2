## 과제 2 관련 (8단계, 보드 A)

### E8-1. 세 모드 실행과 속도 (3차, 2026-10-23 16:55~17:01 KST, main `484b706`)
- 조건: 1280x720, `yolo11n.pt`/`yoloe-11s-seg.pt` PyTorch, 임베딩 배치 2.
- 결과: 검출 fps yolo 12.9 / relabel 12.4 / yoloe 12.3, 임베딩 691 / 677 / 653 ms/개, RAM 최대 6111 / 6182 / 5736 MB, 도는 중 available 최저 1206 MB.
- 판정: 실행·속도 기준(relabel ≥ 10fps) **충족**. TensorRT 엔진은 만들지 않음.

### E8-2. COCO 밖 물체 라벨 비교 (1·2·3차)
- 조건: 컵·노트북·휴대폰(COCO) + 드럼 세탁기(모니터에 띄운 사진)·원통형 전지 포장·건전지 AAA. 판정은 사람이 영상 박스 이름을 보고 적음.
- 결과(3차): yolo 세탁기→전자레인지, 건전지→책 / relabel 둘 다 정답 / yoloe 세탁기 정답, 건전지→책. 전지 포장은 실물이 없어 "물체 없음".
- 판정: 원래 기준으로 **미통과** (표 한 줄 빈칸). 1차는 숫자 기록 빠짐, 2차는 relabel이 휴대폰을 키보드로 잘못 고침 → 3차에 `KEEP_MARGIN 0.03` 규칙을 넣어 해결.

### E8-3. 텍스트 검색
- 조건: 웹 `/search`에 "세탁기", "건전지".
- 결과: 3차 세 모드 모두 1위가 맞는 물체(0.736~0.760). 이름이 틀린 크롭도 검색으로는 찾음.
- 판정: 검색 동작 **충족**.

## 과제 4 관련 (9단계, 보드 A)

### E9-1. raw vs 다수결 안정화 (1차 2026-10-23, 2차 2026-10-26)
- 조건: `yolo11n-pose.pt`, 1280x720, 12.4~12.7fps, 1명, 동작마다 3회. 다수결 창 0.6초.
- 결과: 만세(실제 6) raw 16 → smooth 3(1차) / 7(2차), 한팔들기(실제 3) raw 37 → 5 / 7.
- 판정: 깜빡임은 크게 줄었으나 횟수가 실제와 정확히 같지는 않음. 과제의 "10회 중 9회, 깜빡임 ≤ 1" 형식으로는 재지 않음.

### E9-2. 손 흔들기
- 조건: 1차는 어깨 높이로 흔듦, 2차는 팔을 머리 위로 들고 흔듦.
- 결과: 1차 `WAVE` 0/3, 2차 5번 기록(실제 3번, 손흔들기↔한팔들기가 번갈아 부풂).
- 판정: 원래 기준(3번 중 2번) **2차 통과**. "한팔 들고 정지" 10회 구분 시험은 미수행.

### E9-3. 행동 패턴 규칙 12회 시험 (2026-10-26 09:56~10:02 KST, main `a5eb59d`)
- 조건: `--behavior`, 카메라 아래에서 위로 비스듬히, 2~3m, 1명, 시나리오 4개 × 3회.
- 결과: **12회 중 4회** (지나감 0/3, 힐끗 봄 2/3, 관심 있음 2/3, 머무름 0/3), 15.7fps.
- 판정: **미통과** (원래 기준 8회, 과제 기준 10회).

### E9-4. GRU 학습 모델 보드 비교 (동작 2차, 행동 3차)
- 조건: 맥 CPU에서 학습, 보드에서 `--model`. 참여자 1명(학습·평가 같은 사람).
- 결과: 동작 모델 검증 0.641, 보드에서 박수·팔짱을 알아봄(규칙으로는 불가). 행동 모델 검증 1.000(조각 적음), 보드 시나리오 1~3 **9번 중 7번**(관심 있음 3/3), 15.2fps.
- 판정: 학습 모델 기준 **3차 충족**. "녹화에 참여하지 않은 사람" 시험은 **못 함**(참여자 1명).
